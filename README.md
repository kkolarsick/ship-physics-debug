# Ship Physics Debug

Local project for the ship debugging work from Codex.

## Context

The prior debugging pass focused on procedural ship parts separating during physics simulation. The intended fix was to keep these generated parts connected:

- Hull
- Bow
- Deck
- Mast
- Sail
- Cannons

The bow cosmetic color should also follow the ship hull color for consistent visuals.
